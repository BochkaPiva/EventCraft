# MVP: рабочая спецификация

Обновлено 6 ноября 2026 года. Эти документы описывают выбранный для реализации первый серверный срез и предлагаемые границы закрытого пилота. Исследования в discovery/research сохраняются как обоснование и варианты развития; весь их объём не входит в MVP.

Цель первого продаваемого продукта: менеджер собирает предложение в бренде агентства, клиент открывает защищённую ссылку, предлагает разрешённое изменение, менеджер выпускает обновление. Этот цикл должен работать как без площадки, так и с одной подготовленной реальной площадкой, расстановкой и прогулкой.

## Что существует сейчас

| Часть | Фактическое состояние |
| --- | --- |
| Интерактивный интерфейс | Отдельный [учебный прототип](../../prototype/README.md), локальное хранение, синтетические данные |
| Доменный модуль | TypeScript: документ, расчёт, проверка ревизии, безопасная проекция клиентского снимка |
| База | SQL-миграция: агентства, участники, приватные черновики, серверные операции и RLS |
| Сервер | Next.js: закрытые API, проверка сессии, Origin, входных данных и размера тела |
| Вход и кабинет нового приложения | Ещё не подключены к реальному Auth и базе; главная страница сообщает о подготовке запуска |
| Публикация, клиентские правки, хранение файлов | Контракты проектируются; в серверном приложении ещё не реализованы |
| Production | Не развёрнут; провайдер и расходы не выбраны |

Работающий прототип нельзя принять за новый серверный MVP. У них разные хранилища, порты и назначение. Данные из localStorage автоматически не импортируются.
