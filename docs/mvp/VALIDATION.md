## SQL-сценарии

Реальная миграция применена в свежую PGlite. Пользовательские запросы исполняются с SET ROLE authenticated/anon, роль проверяется тестом. Администратор используется только для устройства фикстуры и проверки запретов. auth.uid моделирует субъект, уже проверенный внешним шлюзом.

Проверены: атомарный первый owner; запрет повторного создания агентства тем же субъектом; чтение/создание/сохранение чужого КП; запрет прямой записи и самоповышения роли; успешное сохранение и отказ устаревшей ревизии без изменения документа; повреждённые вложенные структуры и лишние поля через прямой RPC; работа manager и отзыв участия; аноним/отсутствующий субъект; блокировка principal без самовосстановления; полный откат при сбое первого membership; RLS всех прикладных public-таблиц и отсутствие public SECURITY DEFINER.

Независимый разбор выявил различие HTTP и SQL в обработке пустого имени из табуляций/переносов. Исправлена SQL-нормализация, добавлены проверки обычных и Unicode-пробелов и нормализации заголовка через прямой RPC. Критичных ошибок изоляции в просмотренном M0 при разборе не обнаружено; это не замена полноценному security-аудиту.

## Где заканчивается проверка

| Граница | Статус |
| --- | --- |
| Статическая главная → браузер | Проверена |
| HTTP → конфигурация закрытого API → ответ | Проверена запущенным production runtime |
| Проверенный субъект → SQL-права → данные | Проверена в PGlite, с тестовым auth.uid |
| Браузерный вход → cookies → Supabase Auth → PostgREST → SQL | Не проверена, работающий стек ещё не подключён |
| Две настоящие параллельные транзакции | Не проверены, у PGlite одно соединение |
| Выпуск / клиентские варианты / файлы | В серверном M0 ещё не реализованы |
| Docker-образ | Dockerfile подготовлен; сборка не выполнена без демона |
| GitHub Actions | Workflow добавлен; удалённый запуск пока не выполнен |

Локальная команда advisors запускалась: npm run db:cli -- db advisors --type all --level warn --fail-on warn. Она получила ECONNREFUSED 127.0.0.1:54322: локальный Supabase PostgreSQL не запущен. Поэтому advisors не считается пройденным. Облачный проект не создавался, миграция в удалённую БД не применялась.

## Воспроизведение

Из корня: npm ci → npm run typecheck → npm test → npm run build. Для smoke нужно отдельно запустить собранный сервис с пустыми SUPABASE_URL/SUPABASE_PUBLISHABLE_KEY, затем npm run smoke:unconfigured. Скрипт допускает только loopback HTTP и специально ожидает ненастроенную среду; не запускать его как проверку готовности подключённого production.

Следующая проверка: полный синтетический сеанс двух агентств на настоящем Auth/PostgREST, реальный 409 между двумя соединениями и advisors. Локальные результаты не дают основания переносить реальные сметы в зарубежный бесплатный проект.
