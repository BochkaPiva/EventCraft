# EventCraft — интерактивный прототип

Локальное приложение для проверки полного процесса агентства и получателя предложения. Это рабочий интерфейс на демонстрационных данных, а не production SaaS.

## Что можно пройти

- Первый вход с названием агентства или заполненный пример.
- Список КП, поиск, отбор, независимая копия и архив.
- Правка непосредственно в документе: обложка, идея, программа, необязательная площадка, команда и расчёт. Заготовка заполняет пустые разделы, сохраняя введённое.
- Загрузка фотографий, перестановка разделов, отмена действий и локальное сохранение.
- Учебный зал 16 × 12 м: план, объём и прогулка на одной сцене. Добавление, перемещение, поворот, возврат мебели, коллизии, параметрические сцена/танцпол, подсчёт посадки.
- Отдельные опубликованные снимки содержания и оформления. Публикация, копирование ссылки и отправка ответа — разные действия.
- Клиентский просмотр, личные именованные планы с миниатюрами, пожелания с явным приложением варианта, ответы менеджера и обновлённые выпуски.
- Настройки бренда, локальная команда и демонстрационные сценарии подписки.

## Локальный запуск

Node.js 22.12+; проверено на Node.js 24.14.1.

```powershell
cd prototype
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
```

Проверка собранного интерфейса:

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

Ссылка: <http://localhost:4173/>. Заполненный пример доступен на первом экране. Клиентский демонстрационный код показан в диалоге публикации.

## Проверки

```powershell
npm test
npm run test:sites
npm audit
```

Основные тесты проверяют отделение публикации от черновика, вложенную клиентскую проекцию, неизвестные цены, геометрию и восстановление повреждённого локального состояния. Проверки упаковки не означают внешнее размещение приложения. [Журнал UX-проверок](UX_REVIEW_LOG.md), [визуальная проверка](design-qa.md).

## Границы прототипа

Данные находятся в `localStorage` этого браузера и этого origin. `localhost` и `127.0.0.1` имеют независимые данные. Ссылки не передают КП на другое устройство. Роли проходят последовательно; синхронное редактирование в нескольких вкладках/устройствах не реализовано. Демонстрационный код и локальный идентификатор посетителя показывают сценарий, они не обеспечивают авторизацию или изоляцию агентств. Использовать только учебные материалы.

Письма и платежи не отправляются. Числа тарифов и условия демонстрационные; лимиты не применяются сервером. Показатель объёма материалов иллюстративный. Отключение продления сохраняет учебные предложения. Сброс демо удаляет его локальные данные после подтверждения.

Геометрия зала вымышленная. Коллизии и посадка проверяют согласованность этой сцены; они не подтверждают реальные замеры, нормативную вместимость, безопасность проходов или доступность мебели. Создания реального зала по фото, навигационного паспорта и импорта моделей здесь ещё нет.

3D-модуль загружается отдельно при открытии пространства; сборка сообщает о его размере. Производительность на слабых телефонах и с реальными моделями пока не измерена. Богатое форматирование текста, произвольные композиции, PDF-экспорт, несколько залов/погодных сценариев, права на отдельные блоки и кабинет владельца платформы — следующие продуктовые решения, не скрытые готовые функции.

Перед production требуются российский серверный контур, БД и объектное хранилище, настоящая авторизация и разграничение доступа, серверная клиентская проекция, фоновые задачи, резервное копирование с проверкой восстановления, мониторинг, платежи и тест реальной площадки. Поставщик инфраструктуры этим прототипом не выбран.
