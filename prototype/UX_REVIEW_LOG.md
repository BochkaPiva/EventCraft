# Проверка сквозного прототипа — 6 ноября 2026

Проведено 12 внутренних циклов «возражение или проверка → изменение → повторный проход». Это проектные проверки по ролям агентства и заказчика на синтетических данных. Они не являются интервью с пилотными агентствами, измерением превосходства над PowerPoint или подтверждением production-готовности.

Работали с реальным браузерным интерфейсом, собранным приложением и тестами предметной модели. Отдельный проход получателя использовал `127.0.0.1:4173`; основной — `localhost:4173`, поэтому данные проверок не смешивались. После доработок собранная версия проверена повторно.

## Проверки сборки

- `npm run build` — успешно. 3D загружается отдельным модулем; остаётся предупреждение о размере этого модуля, около 144 КБ gzip. Это не замер загрузки на реальном устройстве.
- `npm test` — 42 теста успешно.
- `npm run test:sites` — 4 проверки упаковки успешно. Размещение не выполнялось.
- `npm audit` — 0 известных уязвимостей на момент проверки. Это не аудит безопасности приложения.
- Браузер: ввод, заготовки, фото/reload, поиск/возврат, зал, коллизия, удаление/Undo, WebGL, публикация/копирование, неправильный код, мобильное чтение, личный план/reload, приложение/reload, пожелание/ответ, Undo/выпуск, старые ссылки, оформление, команда, тариф/отмена, фокус диалогов.

## Что ещё нужно проверить

Реальные менеджеры и заказчики должны пройти задания с собственными материалами: измерить время до пригодного КП, число ошибок и потребность в помощи. Отдельно остаются 40+ КП в списке, длительная работа, слабые телефоны, реальные модели и физические обмеры. Серверные права, конкурентные изменения, доставки, платежи и восстановление резервной БД этим прототипом не проверялись. Полный объём и ограничения перечислены в [README](README.md).
